# 校园多档口点餐 · 本地交互展示版

一个基于 Vue 3 与 uni-app 的校园餐饮聚合原型。项目采用“餐厅—档口—餐品”三级结构，覆盖盖饭、粉面、河南风味、饺子馄饨、轻食烘焙和饮品甜品。无需后端、账号或地图密钥，可直接在浏览器完整演示，同时保留微信小程序构建能力。

## 展示内容

- 首页：当前餐厅、取餐方式、活动、跨档口推荐与会员成长
- 餐厅：默认定位河南农业大学软件学院（许昌校区），展示附近就餐地点
- 点餐：6 个档口、24 道餐品、搜索、规格选择与购物车
- 结算：取餐时间、优惠券、备注、支付方式和本地模拟支付
- 订单：取餐码、制作进度、状态推进、历史订单与再次点餐
- 我的：积分、优惠券、收藏、进行中订单与演示设置
- 数据：购物车、订单、收藏和积分通过本地存储保留，可一键重置

## 直接运行

```bash
npm install
npm run dev:h5
```

终端显示地址后，用浏览器打开即可。常见地址为 `http://localhost:5173/`。

## 构建

```bash
# 浏览器展示版
npm run build:h5

# 微信小程序产物（需要微信开发者工具才能打开产物）
npm run build:mp-weixin
```

构建产物分别位于 `dist/build/h5` 与 `dist/build/mp-weixin`。

## 推荐演示路径

1. 首页选择“到店自取”并进入点餐。
2. 在左侧切换不同档口，查看每个档口的 4 道代表餐品。
3. 选择盖饭或粉面，调整份量、辣度和加料。
4. 加入购物车，在结算页选择优惠券并提交模拟订单。
5. 在订单详情页推进“制作中 → 待取餐 → 已完成”。
6. 进入“我的订单”体验再次点餐。

## 技术说明

- 业务数据集中在 `src/data/catalog.js`。
- 全局演示状态集中在 `src/store/app.js`，不依赖额外状态库。
- 页面只依赖 uni-app 基础组件，核心流程完全离线。
- 每道餐品均绑定独立且与名称对应的商品图，加载失败时仍提供文字降级。
- 地图默认定位河南农业大学软件学院附近；支付、定位和会员信息仅用于产品展示，不发起真实交易或采集真实位置。
